# S2GOS

Synthetic scene generation and observation simulation for Earth observation.

See the [documentation](https://s2gos-dev.github.io/s2gos-mono/) for usage, examples, and API reference.

## Setup

New here? Follow [SETUP.md](SETUP.md) — it goes from installing pixi to running an example.

Short form, if you already have the data:

```bash
pixi install --frozen
pixi run --frozen eradiate-init
```
