    Products

    Writers that combine the per-band results of a satellite sensor into one store laid out like the mission's real product, one module per mission. A sensor asks for one with its output_format (e.g. output_format="eopf" for a Sentinel-2 MSI sensor), which picks the writer from s2gos_simulator.products.PRODUCT_WRITERS, which names the store. Sensors without it keep one store per band, <sim>_<sensor id>_<band>.zarr, or <sim>_<sensor id>.zarr for a hyperspectral sensor.

    Sentinel-2

    s2gos_simulator.products.sentinel2

    Combine the per-band results of a Sentinel-2 MSI sensor into one EOPF-like L1C store.

    The store is an xr.DataTree laid out like ESA's EOPF Sentinel-2 L1C product::

    /                                      attrs: stac_discovery, other_metadata
measurements/reflectance/r10m|r20m|r60m  b02, b8a, ... on (y, x), uint16 counts
conditions/geometry                    mean_sun_angles (angle),
                                       mean_viewing_incidence_angles (band, angle),
                                       sun_angles (angle, y, x),
                                       viewing_incidence_angles
                                       (band, detector, angle, y, x)
conditions/mask/detector_footprint/rNNm  b02, ... uint8 detector number
conditions/mask/l1c_classification/r60m  b00 uint8 cloud/snow bitmask
quality/mask/r10m|r20m|r60m            b02, ... uint8 quality bitmask
quality/l1c_quicklook/r10m             tci (band, y, x) uint8, only when B02/B03/B04
                                       are all simulated

    Each band stays on the grid it was rendered at, with no resampling, and all bands share the footprint's upper-left corner. The store is in the CRS of the sensor's projected_grid. Reflectance is stored as L1C digital counts (see REFLECTANCE_ENCODING) and decodes to float on open. Angles follow the Sentinel-2 convention (azimuth from north, clockwise). The masks describe a simulated scene: one detector, no clouds or snow, and only pixels clipped to the largest storable count flagged saturated_pixel. Open with xr.open_datatree(path, engine="zarr").

    ANGLE_GRID_STEP_M module-attribute 

    ANGLE_GRID_STEP_M = 5000.0

    Node spacing of the L1C sun and viewing angle grids.

    CLASSIFICATION_ATTRS module-attribute 

    CLASSIFICATION_ATTRS = {
    "long_name": "cloud classification bitmask provided in the final reference frame (ground geometry)",
    "flag_masks": [1, 2, 4, 128],
    "flag_meanings": [
        "opaque",
        "cirrus",
        "snow_ice",
        "novalue",
    ],
}

    EOPF attributes of the conditions/mask/l1c_classification/r60m b00 mask.

    CLASSIFICATION_PIXEL_M module-attribute 

    CLASSIFICATION_PIXEL_M = 60.0

    Pixel size of the cloud classification mask.

    DETECTOR module-attribute 

    DETECTOR = 'd01'

    Detector of the whole footprint, in the angle grids and the detector footprint mask.

    DETECTOR_FOOTPRINT_ATTRS module-attribute 

    DETECTOR_FOOTPRINT_ATTRS = {
    "long_name": "detector footprint mask provided in the final reference frame (ground geometry)",
    "flag_values": list(range(13)),
    "flag_meanings": ["no_detector"]
    + [f"d{i}" for i in (range(1, 13))],
}

    EOPF attributes of conditions/mask/detector_footprint bands.

    MAX_REFLECTANCE module-attribute 

    MAX_REFLECTANCE = (
    REFLECTANCE_ENCODING["add_offset"]
    + max * REFLECTANCE_ENCODING["scale_factor"]
)

    Largest reflectance REFLECTANCE_ENCODING can store. Larger values are clipped to it.

    QUALITY_MASK_ATTRS module-attribute 

    QUALITY_MASK_ATTRS = {
    "long_name": "quality mask provided in the final reference frame (ground geometry)",
    "flag_masks": [1, 2, 4, 8, 16, 32, 64, 128],
    "flag_meanings": [
        "anc_lost",
        "anc_deg",
        "msi_lost",
        "msi_deg",
        "defective_pixel",
        "no_data_pixel",
        "partially_corrected_pixel",
        "saturated_pixel",
    ],
}

    EOPF attributes of quality/mask bands.

    REFLECTANCE_ENCODING module-attribute 

    REFLECTANCE_ENCODING = {
    "dtype": "uint16",
    "scale_factor": 0.0001,
    "add_offset": -0.1,
    "_FillValue": 0,
}

    On-disk encoding of L1C reflectance (processing baseline 04.00 onwards).

    SATURATED_PIXEL module-attribute 

    SATURATED_PIXEL = 128

    quality/mask bit of a pixel clipped to MAX_REFLECTANCE.

    SUN_DISTANCE_FACTOR_KEY module-attribute 

    SUN_DISTANCE_FACTOR_KEY = "reflectance_correction_factor_from_the_sun_earth_distance_variation_computed_using_the_acquisition_date"

    EOPF other_metadata key of the Earth-Sun distance factor U = (1 AU / d)².

    TCI_MAX_REFLECTANCE module-attribute 

    TCI_MAX_REFLECTANCE = 0.357

    TOA reflectance mapped to 255 in the TCI quicklook, linear from 0.

    ESA does not publish the L1C TCI stretch. This value reproduces the tci of EOPF L1C samples to within one count.

    product_name 

    product_name(
    sensor: SatelliteSensor,
    illumination: Illumination,
    simulation_name: str,
) -> str

    Store name, e.g. S2A_MSIL1C_20240622T091715_gobabeb_s2.zarr.

    It starts like an ESA L1C product name, which EOPF readers such as xarray-eopf use to recognize the product type. The sensing time is left out when the illumination has none, and taken as UTC when naive.
