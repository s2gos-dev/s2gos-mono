# S2GOS Common

Shared components for the ESA DTE-S2GOS service.

## Overview

This package contains common functionality shared between the S2GOS generator and simulator packages:

- **Scene Descriptions**: Classes for representing and serializing scene descriptions
- **Materials**: Material definitions and handling for BRDF models
- **File I/O**: Unified file access utilities with fsspec support for local and remote storage
- **Serialization**: Common utilities for YAML/JSON serialization
